# Tenkay planet graph — S2 face 5

Graph data for `planet-260824-v4`, distributed as gzip-compressed TKM1 layout-2
blocks. Layout 2 adds conservative per-edge spherical bounding boxes. Decompress
`.tkm.gz` to obtain a memory-mappable little-endian file. IDs use `s2-midpoint-v2`.
Catalogues pin immutable commits; the original layout-1 release remains in its
separate repositories.
